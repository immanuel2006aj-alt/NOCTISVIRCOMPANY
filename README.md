# NOCTIS TECHNOLOGIES

Virtual web-development agency. Human-led delivery, coordinated by a
defined team of AI agents.

This repository contains the public website: landing, team directory,
services, boardroom (demo), and contact.

---

## Stack

- **Next.js 15** (App Router)
- **React 19**
- **TypeScript 5.6**
- **Tailwind CSS 3.4**
- **lucide-react** for SVG icons
- **DiceBear** for generated agent avatars

---

## Requirements

- Node.js **v18.18 or newer** (v20 LTS recommended)
- npm **v9 or newer**

---
